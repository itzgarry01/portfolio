# Artist Garry — Motion Graphics & Visual Art Portfolio

A warm, creamy, aesthetic motion graphics and visual art portfolio for **Artist Garry** (`@igxrrry`), featuring high-contrast commercial advertising, retro automotive posters, Sikh heritage digital paintings, an interactive cartoon sticker lab, and responsive full-bleed galleries.

## 🎨 Features
- **Spotlight 5/5 Albums**: Sher-E-Khalsa (Baba Deep Singh Ji), Parkash Purab, Mega Sale Headphones, 1969 Ford Mustang, and Nike KD17.
- **Visual Archive Gallery**: 19 curated full-bleed artworks with category filters and interactive lightbox carousel.
- **Motion & Physics Engine**: GSAP 3, ScrollTrigger, Lenis smooth scrolling, scroll-coupled marquees, and eyeball tracking mascot.
- **Interactive Audio**: Web Audio API tactile mechanical click synthesizer with header mute toggle.
- **Live Commission Inquiries**: FormSubmit API directly delivering inquiries to `artist.gxrry@gmail.com`.

## 🛠️ Built With
- Vanilla HTML5 + CSS3 (No framework bloat)
- Modern ES6+ JavaScript
- GSAP 3.12.5 + ScrollTrigger
- Studio Freight Lenis
- Lucide Icons
- Web Audio API
